## מה קיים

הרשמה וכניסה בדוא״ל, ניהול פרויקטים, שאלון ציבורי באמצעות קישור, שמירת תשובות, ניתוח AI ותצוגת שמונה פרקי תוצאות. קיימת פונקציה להדמיות חדרים, אך היא אינה מחוברת למסך משתמש.

## התחלה מהירה

בעותק מקומי של קוד האפליקציה:

```sh
bun install
bun run dev
bun run test
```

נדרש חיבור ל־Lovable Cloud והגדרת משתני הסביבה המתוארים במדריך ההתקנה; התקנת החבילות לבדה אינה מפעילה את השירותים.

## גבולות התיעוד

התיעוד מבוסס על קוד הפרויקט שנבדק ב־24 באוקטובר 2026, ולא על אימות הגדרות השירות החי. התוכנית ההיסטורית אינה הוכחה לכך שכל תכונותיה נבנו. אין להציג ייצוא PDF, שליחת דוא״ל, שיתוף תוצאות או הדמיות במסך כיכולות פעילות.

**לפני שימוש עם מידע אמיתי:** יש לבדוק ולצמצם הרשאות ציבוריות ולוודא בדיקת בעלות בפונקציות AI; ראו מדריך האבטחה.

המסמכים אינם כוללים מפתחות, מידע אישי או נתוני לקוחות. העברתם למאגר אינה פרסום האפליקציה ואינה חיבור סנכרון Git.
