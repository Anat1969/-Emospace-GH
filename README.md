## מה קיים

הרשמה וכניסה בדוא״ל, ניהול פרויקטים, שאלון ציבורי באמצעות קישור, שמירת תשובות, ניתוח AI ותצוגת שמונה פרקי תוצאות. קיימת פונקציה להדמיות חדרים, אך היא אינה מחוברת למסך משתמש.

## EMOSPACE 2 במאגר הזה

בתיקיית `app/` נבנתה גרסה עצמאית שפועלת בדפדפן בלבד: שאלון חושי עם צלילים ואור חיים, ניתוח מקומי לשמונה פרקים וחדר תלת־ממדי שנבנה מהתוצאות, עם מחזור יום ונוף קולי. היא אינה מחוברת ל-Lovable Cloud ושומרת נתונים במכשיר. פרטים, מה נבדק ומה לא: [docs/APP.md](docs/APP.md).

```sh
cd app && npm install && npm run dev
```

## התחלה מהירה (האפליקציה המקורית ב-Lovable)

בעותק מקומי של קוד האפליקציה:

```sh
bun install
bun run dev
bun run test
```

נדרש חיבור ל־Lovable Cloud והגדרת משתני הסביבה המתוארים במדריך ההתקנה; התקנת החבילות לבדה אינה מפעילה את השירותים.
