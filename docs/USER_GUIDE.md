# מדריך שימוש

## תהליך האדריכל

1. נכנסים לעמוד הכניסה ונרשמים או מתחברים בדוא״ל וסיסמה.
2. עוברים לרשימת הפרויקטים ויוצרים פרויקט עם פרטי הלקוח והמרחב.
3. פותחים את הפרויקט ומשתפים עם הלקוח את קישור השאלון המוצג בו.
4. לאחר מילוי השאלון בודקים את התשובות ומפעילים ניתוח AI.
5. פותחים את התוצאות ועוברים בין שמונת פרקי המפה האדריכלית־רגשית.

הקוד מציג הודעת אישור דוא״ל בהרשמה; דרישת האישור בפועל תלויה בהגדרות השירות ולא אומתה במסגרת התיעוד.

## תהליך הלקוח

השאלון נפתח בקישור אישי ללא חשבון לקוח. חלקיו: רגש ליבה, צבע, זיכרון מקום, נוף קולי, אור, מרקם והעדפות מרחב. התשובות נשמרות לפי חלק, והפתיחה החוזרת מתקדמת לחלק הראשון שלא נענה. בסיום החלק האחרון מוצג מסך סיום.

קישור השאלון אינו מנגנון הרשאה מספק בפני עצמו במצב הקוד הנוכחי; אין להשתמש בו למידע רגיש לפני השלמת בדיקת האבטחה.

## קריאת התוצאות

המסמך כולל פרופיל רגשי, צבע, גובה ופרופורציות, תאורה, חומרים, אקוסטיקה, מעברים ולוח זמנים. התוצאות הן המלצות AI, לא הוראות ביצוע מאושרות; יש לאמת מידות, תקנים, חומרים והתאמה מקצועית.

## פעולות ניהול

לפי תקן הפרויקט, פעולות עריכה ופיתוח מרוכזות בתפריט הלוגו „אד' ענת שטיבלמן A&I”. אין להוסיף אותן ככפתורים עצמאיים בסרגל העליון. מחיקת פרויקט דורשת זהירות: יש לבדוק גיבוי והשלכות על רשומות קשורות לפני ביצוע.
