# אפליקציית EMOSPACE 2 (תיקיית `app/`)

גרסה עצמאית ומקומית של EMOSPACE שנבנתה במאגר הזה. היא פועלת בדפדפן בלבד, בלי Lovable Cloud ובלי שירות AI חיצוני. אין לה קשר לנתונים של האפליקציה המקורית ב-Lovable.

## הפעלה

```sh
cd app
npm install
npm run dev      # פיתוח
npm test         # בדיקות מנוע הניתוח
npm run build    # אריזה ל-app/dist
```

התוצר ב-`app/dist` הוא אתר סטטי. הניווט מבוסס על `#` בכתובת, ולכן רענון של עמוד פנימי אינו מחזיר 404 גם באירוח פשוט.

## מה נבדק בקוד ובדפדפן

| תחום | מצב |
| --- | --- |
| יצירת פרויקט, רשימה, חיפוש, עריכה ומחיקה (מחיקה רק במצב עריכה בתפריט A&I) | נבדק בדפדפן |
| שאלון בשבעה חלקים, כולל השמעת מקורות קול, תצוגת גוון אור וחתך מרחב חי | נבדק בדפדפן |
| קישור שאלון ללקוח במכשיר אחר, קישור החזרה וקליטת התשובות | נבדק בדפדפן (שני הקשרי דפדפן נפרדים) |
| ניתוח מקומי לשמונה פרקים, חדרים מומלצים ותובנות | בדיקות יחידה (`npm test`) ובדפדפן |
| חדר תלת־ממדי: תקרה, קימור, חלון, חומרים, צמחייה, נישת מחסה ומים לפי הניתוח | נבדק בדפדפן ללא GPU (SwiftShader) |

| התקנה כאפליקציה (manifest ו-service worker) | ממומש; לא נבדק על מכשיר |

## מנוע הניתוח

`app/src/lib/engine.ts` מתרגם את התשובות לווקטור של עשרה ערכים בין 0 ל-1 (אנרגיה, טמפרטורה, פתיחות, מחסה, קימור, טבע, שכבתיות, אור יום, רגישות לרעש, תקרה). מהווקטור נגזרים הפלטה (60/25/10/5), גובה התקרה (2.5–3.6 מ'), תוכנית אור לפי שעות היממה, קוד חומרים, יעד זמן הדהוד, רצף מעברים ולוח זמנים. אותן תשובות נותנות תמיד אותה תוצאה.

העקרונות שהמנוע נשען עליהם מפורטים ב-`app/src/lib/insights.ts` ובעמוד "תובנות" באפליקציה, עם מקורות. אלה כיווני מחקר, לא חוקים, וכל המלצה דורשת שיקול דעת של אדריכל.

## נתונים ופרטיות

- הפרויקטים נשמרים ב-`localStorage` של הדפדפן במכשיר שבו נוצרו. ניקוי נתוני האתר מוחק אותם; לגיבוי משתמשים ב"ייצוא גיבוי" בתפריט A&I.
- קישור השאלון מכיל את שם הלקוח וסוג הפרויקט. קישור ההחזרה מכיל את תשובות הלקוח, וקישור שיתוף התוצאות מכיל את הניתוח. הם מקודדים אך **אינם מוצפנים**: כל מי שמחזיק בקישור יכול לקרוא את התוכן. אין לשלוח בהם מידע רגיש.
- שום תשובה אינה נשלחת לשרת או לשירות AI. האפליקציה טוענת גופנים מ-Google Fonts ואת כפתור A&I מ-`appofapp-gh.vercel.app`.

## כפתור A&I

הסרגל העליון מכיל רק את שם האפליקציה, את הניווט (פרויקטים, תובנות) ואת `<ai-menu>`. פעולות העריכה (מצב עריכה, פרויקט חדש, פרויקט לדוגמה, מחיקת הפרויקט, ייצוא וייבוא גיבוי) מועברות אליו דרך `menu.items` ב-`app/src/components/AIMenu.tsx`. בעמודי הלקוח (שאלון ותוצאות משותפות) התפריט אינו מציג פעולות עריכה.

## גבולות

- אין חשבונות משתמש ואין סנכרון בין מכשירים.

- ההדמיה היא סכמה אווירתית ולא תכנית מדודה.
