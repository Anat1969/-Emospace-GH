# בדיקות ופתרון תקלות

## מצב הבדיקות

בפרויקט קיימים Vitest ותשתית בדיקות, אך הבדיקה שנמצאה היא בדיקת דוגמה בלבד. מעבר שלה אינו מוכיח תקינות תהליך, הרשאות או ניתוח AI.

```sh
bun run test
```

לא בוצעה במסגרת התיעוד בדיקת כניסה, שאלון וניתוח עם חשבון אמיתי.

## רשימת בדיקה מקצה לקצה

- הרשמה, אישור לפי הגדרות השירות, כניסה ויציאה.
- יצירת פרויקט והופעתו ברשימה ובפרטים לאחר רענון.
- פתיחת קישור שאלון ללא חשבון ומילוי כל שבעת החלקים.
- חזרה לשאלון ובדיקת תשובות שמורות וסיום.
- ניתוח עם יתרה זמינה, קריאת התוצאה השמורה ופתיחת כל שמונת הפרקים.
- טיפול בכשל ניתוח ללא אובדן תשובות או מסך ריק.
- שתי זהויות שונות: מניעת גישה לפרויקטים ולתוצאות של האחר.
- גישה ציבורית: בדיקה שלא ניתן לקרוא או לשנות פרויקט באמצעות מזהה אחר.
- תצוגה צרה ורחבה, עברית, ניווט מקלדת ותפריט A&I.

בדיקות הרשאה יש לבצע בסביבת בדיקה עם מידע מלאכותי. אין למחוק פרויקט אמיתי לצורך בדיקה.

## תקלות נפוצות

| סימפטום | בדיקה ופעולה |
| --- | --- |
| 402 בניתוח | לבדוק ולהוסיף יתרת Cloud & AI; שינוי קוד לא מחליף יתרה |
| 429 | להמתין ולנסות שוב; להציג הודעה ללא אובדן תשובות |
| שגיאת DNS ל־AI | לוודא `ai.gateway.lovable.dev` ולא `ai-gateway.lovable.dev` |
| 404 ברענון כתובת פנימית | לבדוק הגדרת החזרת האפליקציה באירוח |
| לא נמצאו תוצאות | לבדוק רשומת ניתוח, הרשאות ופלט מובנה |
| תוצאה ריקה אחרי ניתוח | לבדוק אם נשמר `raw_analysis` במקום הפרקים |
| כניסה אינה מצליחה | לבדוק הגדרות השירות החי; הודעה בקוד אינה מוכיחה שהגדרה פעילה |

באיסוף ראיות יש להסיר אסימונים, תשובות אישיות ופרטי לקוחות מיומנים וצילומי מסך.
